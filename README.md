# my-project
Superstore Sales Dashboard
An interactive Power BI report for exploring sales, profit, customers, products, and regional performance using a Superstore-style retail dataset.
Dashboard pages
The PBIX contains six report pages:
1. Home – landing page and navigation to the report.
2. Sales Overview – high-level sales performance and overview visuals.
3. Profit – profit analysis, including product-category filtering (Technology, Furniture, and Office Supplies).
4. Customer Report – customer-focused metrics, including total customers, previous-year customer comparison, and customer ranking/highlights.
5. Product Analysis – product-level analysis, including a Top 15 Products view and category filtering.
6. Regional Sales – regional sales analysis.
Features
- Multi-page report navigation.
- Interactive slicers and dropdown filters.
- Product category analysis.
- Sales and profit performance views.
- Customer and product analysis.
- Regional performance view.
- Custom blue-and-white dashboard styling and background assets.
Requirements
- Microsoft Power BI Desktop (recommended for opening and interacting with the .pbix file).
- Access to the report's underlying data source, if a refresh is required.
Getting started
1. Download or copy power bi dashbord.pbix to your computer.
2. Open the file in Power BI Desktop.
3. Use the page navigation controls to move between report sections.
4. Use slicers and dropdowns to filter the visuals.
5. If Power BI requests credentials or reports a data-source error, configure access to the original source before refreshing.
Data and refresh notes
The report is packaged as a Power BI .pbix file. The source connection details and refresh requirements should be checked in Power BI Desktop under Transform data and Data source settings. The README does not assume a specific file path, database, or refresh credential because those details are not confirmed from the report package.
